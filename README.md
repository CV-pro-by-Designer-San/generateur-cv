# Générateur de CV — Designer_san

Générateur de CV en ligne : deux modèles A4, aperçu en direct, pagination
automatique sur plusieurs pages, export PNG et PDF, interface français / anglais.

L'accès est réservé aux détenteurs d'un code de licence.

## Ce dépôt

Il ne contient que la page publiée (`index.html`). Elle est entièrement
autonome : aucune dépendance à installer, aucune étape de construction.

La vérification des licences est assurée par un service distinct ; **aucun
secret ne figure dans ce dépôt**.

## Mise à jour

Remplacer `index.html` par la nouvelle version, puis :

```bash
git add index.html
git commit -m "Mise à jour du générateur"
git push
```

GitHub Pages republie automatiquement en une minute environ.
